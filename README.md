
# Bang & Olufsen — Responsive Tech Store Website
This project presents a modern tech store website created to help users explore high-quality gadgets and smart devices. The landing page highlights key product categories, showcases featured items, and delivers a clean, intuitive browsing experience. The structure, animations, and responsive design make it easy for users to navigate the page and discover the devices they need

## 🛠️ Technologies Used
HTML · SCSS (BEM) · Tailwind CSS · CSS Grid / Flexbox · Git & GitHub

## 📦 Getting Started
To run the project locally:

1. Clone the repository:
git clone https://github.com/vtmnkmarta/layout_bang-and-olufsen.git
cd layout_landing-page

2. Install dependencies:
npm install
or
yarn install

3. Run the project:
npm start
or
yarn start

## ✅ Features
- Semantic HTML5 structure
- SCSS styling using BEM methodology
- Responsive design: mobile / tablet / desktop
- Clean grid layout and consistent spacing
- Interactive elements and animations
- Optimized for readability, maintainability, and performance
